# Paleta de Colores - Pixel Flowers

- `bg-base` - body, CardInfo
- `bg-accent` - GalleryButton
- `bg-canvas` - FlowerPage (dinámico)
- `bg-placeholder` - CardImage, GalleryItem
- `bg-tab` - BackButton, CardTab
- `text-xmuted` - NotFound (ícono, título)
- `text-muted` - CardInfo (nombre científico), NotFound (mensaje)
- `text-disabled` - GalleryButton (desactivado)
- `text-body` - BackButton (ícono), CardInfo (nombre común, descripción), CardTab (ícono), GalleryPage (título)
- `text-strong` - CardInfo (fecha), GalleryPage (autor)
- `text-emphasis` - GalleryButton (por defecto), GalleryPage (título en hover)

Con esta paleta de referencia se generan las clases personalizadas de [tailwind.config.js](../tailwind.config.js)
