# Paleta de Colores Neutral - Pixel Flowers

## Colores de Background (bg-)

- `bg-neutral-300` - CardInfo, GalleryPage
- `bg-neutral-400` - CardImage, GalleryButton, GalleryItem
- `bg-neutral-500` - FlowerPage
- `bg-neutral-600` - CardTab

## Colores de Texto (text-)

- `text-neutral-400` - NotFound (ícono, título)
- `text-neutral-500` - CardInfo (nombre científico), NotFound (mensaje)
- `text-neutral-700` - CardInfo (nombre común, descripción), GalleryButton, GalleryPage (título)
- `text-neutral-800` - CardInfo (fecha), CardTab (ícono), GalleryPage (autor)
- `text-neutral-900` - GalleryPage (título en hover)

## Coversión a clases

- `bg-base` - CardInfo, GalleryPage
- `bg-accent` - GalleryButton
- `bg-placeholder` - CardImage, GalleryItem
- `bg-tab` - CardTab
- `text-xmuted` - NotFound (ícono, título)
- `text-muted` - CardInfo (nombre científico), NotFound (mensaje)
- `text-body` - CardInfo (nombre común, descripción), GalleryButton, GalleryPage (título)
- `text-strong` - CardInfo (fecha), CardTab (ícono), GalleryPage (autor)
- `text-emphasis` - GalleryPage (título en hover)
- `bg-canvas` - FlowerPage (dinámico)

Con esta paleta de referencia se generan las clases personalizadas de [tailwind.config.js](../tailwind.config.js)
